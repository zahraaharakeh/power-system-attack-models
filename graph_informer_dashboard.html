🔧 Technical Architecture Comparison

🏆 Graph Informer Transformer (78.31% accuracy)

📐 Architecture

  • Design Philosophy: Simple and Clean
  • Model Size: 256 dimensions, 3 layers
  • Attention Mechanism: Simplified multi-head attention (8 heads)
  • Graph Integration: GCNConv for structural information
  • Sequence Length: 24 time steps

🧠 Key Components

  • GraphPositionalEncoding: Standard sinusoidal encoding
  • GraphProbSparseAttention: Simplified attention (not true ProbSparse)
  • GraphInformerBlock: 3 transformer blocks with GCN integration
  • Single Decoder: Simple reconstruction decoder
  • Basic Anomaly Detector: Single sigmoid output

🎯 Training Approach

  • Loss Function: MSE reconstruction + anomaly regularization
  • Optimizer: AdamW with lr=0.0005
  • Training Epochs: 100
  • Early Stopping: 15 epochs patience
  • Gradient Clipping: max_norm=1.0

⚠️ Enhanced Unsupervised Graph Informer (48.68% accuracy)

📐 Architecture

  • Design Philosophy: Complex Multi-Module Design
  • Model Size: 512 dimensions, 6 layers (2x larger)
  • Attention Mechanism: Advanced multi-head attention
  • Graph Integration: Multiple GCN + GAT convolutions
  • Sequence Length: 24 time steps

🧠 Key Components

  • Enhanced Input Projection: 3-layer deep projection with LayerNorm
  • Multiple Decoders: Global, Local, and Temporal reconstruction
  • ContrastiveLearningModule: InfoNCE loss for representation learning
  • TemporalConsistencyModule: Temporal attention + consistency prediction
  • DynamicEnsembleScoring: Multiple anomaly scorers with dynamic weights
  • Multi-Scale Graph Convolutions: Both GCN and GAT layers

🎯 Training Approach

  • Loss Function: 6+ different loss components
  • Loss Components: Reconstruction (3 types), Contrastive, Temporal consistency, Statistical/Pattern, Ensemble regularization
  • Optimizer: AdamW with lr=0.001
  • Training Epochs: 150
  • Early Stopping: 25 epochs patience

🎯 Why the Simple Model Performed Better

🔧 Over-Engineering

The enhanced model is too complex for the available data, leading to overfitting and poor generalization.

Too many competing loss terms create conflicting optimization objectives, preventing convergence.

🎛️ Hyperparameter Sensitivity

More parameters require more careful tuning, making the model harder to optimize effectively.

📈 Training Instability

Complex architectures are inherently harder to train and more prone to gradient issues.
